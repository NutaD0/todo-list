# To do List

Салимов МПБ-301-О-01
Краткое описание:
to do list для заметок, отметок того что запланировано.
Нужно для забывчивых людей, чтобы не забывали свои планы на день.
Довольно удобный интерфейс с возможностью группировать задачи по папкам.

## Стек

- Typescript + React + Tailwind
- Atom, Lucide React, Shadcn ui
- LocalStorage (для пет-проекта только это использовал)

## Быстрый старт

npm run dev
